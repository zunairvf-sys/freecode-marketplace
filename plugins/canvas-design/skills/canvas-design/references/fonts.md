## Usage

```python
from PIL import ImageFont

# Load a font at the desired size
font = ImageFont.truetype('canvas-fonts/InstrumentSans-Bold.ttf', 72)

# Use in drawing
from PIL import Image, ImageDraw
canvas = Image.new('RGB', (1080, 1080), '#faf9f5')
draw = ImageDraw.Draw(canvas)
draw.text((100, 400), 'Hello World', fill='#141413', font=font)
```
